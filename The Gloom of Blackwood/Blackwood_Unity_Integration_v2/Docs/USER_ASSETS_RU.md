# Сборка из твоих готовых ассетов

Твой новый порядок работы: ты собираешь модели, приложение подключает их к подготовленным механикам и собирает карту. Генерация моделей в Blender не требуется. Старый пункт 3 меню оставлен исключительно для необязательного просмотра заготовок.

## Папка

Удобнее всего сложить модели и связанные текстуры в **Assets/GameArt** внутри Unity-проекта. Можно одной папкой. Не отделяй текстуры от модели, если её материал использует относительные пути. Уже добавленного зомби переносить и переименовывать не требуется: приложение найдёт его в текущем проекте.

Для автоматического сканера желательно использовать следующие имена файлов, либо одноимённые подпапки с единственным главным prefab/FBX. Само переименование необязательно, когда подключением занимается приложение по приложенному промпту.

| Роль | Понятное имя |
|---|---|
| Убежище | Shelter |
| Рабочий лагерь | Camp или WorkerCamp |
| Электровышка | Generator или PowerTower |
| Секция стены | Wall |
| Пулемёт | Gun или MachineGun |
| Лаборатория | Lab или Laboratory |
| Электрическая турель | Tesla |
| Дрон | Drone |
| Дерево | Pine |
| Камни | Rubble |
| Посадочная площадка | Pad или DronePad |
| Зомби | Уже существующий prefab; при необходимости Zombie |

FBX может содержать несколько частей одного здания — это нормально. Их не нужно разносить по разным ролям. Prefab предпочтительнее сырого FBX, если в нём уже правильно настроены материалы и Animator.

## Команды и назначение

`Dawn Guard/5 - Scan my assets` создаёт/обновляет `BlackwoodV2/UserAssets.asset`. Назначенные ссылки сохраняются. При нескольких prefab в одной роли сканер не угадывает: роль нужно разрешить в этом asset-файле. Зомби сначала берётся из каталога работающей сцены; затем ищется среди твоих моделей или однозначного экземпляра с Animator в сцене.

`Dawn Guard/6 - Build map with my assets` проверяет необходимые роли, выполняет проверки экономики и создаёт отдельную сцену `Generated/UserMap/BlackwoodUserMap.unity` с копией каталога и prefab-обёртками. Повторный запуск создаёт следующую папку, не перезаписывая предыдущую сцену.

Обязательны семь зданий, дрон и зомби. Камни, дерево и площадка необязательны для логики. Если камней нет, препятствия обозначаются видимыми кубами, о чём выводится предупреждение. Для художественно законченной карты нужно назначить модель камней. Если нет отдельных бегуна/громилы, используются варианты твоего зомби по высоте, с разными параметрами боя.

Обёртки подгоняют здания под сетку и выравнивают основание. Враг нормируется по высоте, чтобы разведённые руки в исходной позе не делали его крошечным. Подгонку размера можно отключить в `Fit Models To Grid`; центрирование точки опоры остаётся. Ориентацию необычно экспортированной модели приложение должно проверить по виду, сканер её не угадывает.

Карта содержит настоящее окружение в сцене и предпросмотр трёх стартовых зданий. При Play предпросмотр удаляется, а ядро создаёт интерактивные экземпляры. Не добавляй отдельный старый GameRoot рядом с BlackwoodRoot: два контроллера создадут две игры.

## Что уже подготовлено для зомби

BlackwoodEnemyView управляет только визуальными параметрами. Имена Speed, IsMoving, IsAttacking, Die — настраиваемые значения; запись происходит только в существующие параметры нужного типа. Отсутствующий контроллер не заменяется придуманным автоматически.

Визуальная атака пока определяется приблизительно: враг остановился около здания. Промпт требует от приложения подключить точное состояние атаки к реальному ядру. При настроенных death trigger и deathSeconds предусмотрена задержка возврата модели в пул; награда выдаётся ядром сразу и один раз. При повторном появлении адаптер сбрасывает Animator. Значение deathSeconds по умолчанию 0, пока не известна настоящая анимация.

Root Motion и NavMeshAgent в новых обёртках отключаются, Rigidbody переводится в kinematic, коллайдеры модели отключаются: здесь движение и занятие клеток вычисляет ядро. Неизвестные пользовательские скрипты не удаляются автоматически. Сборщик выводит их названия, а приложение должно проверить, нет ли второго AI, урона или Animation Events, конфликтующих с механиками.

Скрипт сборки не может достоверно закончить неизвестный Animator по названию FBX. Поэтому **промпт включает проверку твоих реальных клипов, Avatar и контроллеров** и доведение интеграции в локальном редакторе.

## Как дать задание приложению

Положи распакованный пакет рядом с проектом либо добавь его папку BlackwoodV2 в Assets/DawnGuard. Открой проект в локальном приложении и отправь текст из `LOCAL_AGENT_PROMPT_RU.md`. Он содержит и автоматические команды, и требования к проверке результата. Доступ к файлам сам по себе не гарантирует доступ к управлению Unity; приложение должно проверить доступные инструменты и честно обозначить оставшийся ручной шаг, если редактор недоступен.
