# Архив истории

Эта папка не является Unity-проектом и не входит в текущую игру.

`Maintenance-2026-09-10/ValidationProjectDelta` содержит 139 файлов, отличавшихся от рабочего проекта при проверке вложенной тестовой копии. Их SHA-256 проверены после копирования. Источник каждого файла и совпадающие файлы рабочего проекта перечислены в `validation-copy-manifest.json`.

`LegacyIntegrationPackage` — прежний пакет установки V2. Он сохранён как исторический материал, повторно импортировать его поверх текущего проекта не нужно.

`Compile-WithUnityReferences.obsolete.ps1` — прежняя проверка с жёстко заданными путями к кэшу компилятора; для текущей версии не используется. Актуальный запуск и проверки описаны в корневом README_RU.md.
