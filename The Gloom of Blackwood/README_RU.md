# The Gloom of Blackwood

Рабочий Unity-проект. Текущая версия — **BlackwoodLTD / береговой рубеж**, функциональная альфа.

## Запуск

1. Открыть эту папку проекта в Unity **6000.5.4f1**. Дождаться завершения импорта.
2. Открыть `Assets/DawnGuard/BlackwoodLTD/Scenes/BlackwoodCoast.unity`.
3. Нажать **Play**. В меню выбрать «В лагерь» или «Новая экспедиция».

Сцена уже выбрана первой в Build Settings; SampleScene отключена. Для обычного запуска пересобирать карту через меню генератора не требуется.

Днём: выбрать защиту внизу и нажать на поле. Перетаскивание перемещает камеру, колесо меняет масштаб. Ночью защита атакует сама; дрон помогает ремонтом и перегрузкой. Esc отменяет выбор или включает паузу.

## Где что находится

| Путь | Назначение |
|---|---|
| `Assets/DawnGuard/BlackwoodLTD` | Текущая игра: логика, интерфейс, генератор, сцена и добавленные модели |
| `Assets/DawnGuard/BlackwoodV2` | Сохранённый предыдущий прототип; его префабы и ассеты также используются LTD |
| `Assets/DawnGuard/Core` | Общее ядро прежней версии |
| `Assets/GameArt`, `Assets/Enemy` | Пользовательские модели, текстуры и анимации |
| `Packages`, `ProjectSettings` | Зависимости и настройки Unity |
| `Design` | Концепция, актуальный план, аудит размера и требования к ассетам |
| `Tools` | Проверки и подготовка архива исходников |
| `IntegrationEvidence` | Отчёты проверок и локальные служебные команды редактора |
| `Archive` | Исторические материалы и сохранённые отличия тестового проекта; Unity их не импортирует |
| `Library`, `Temp`, `Logs`, `.vs` | Автоматические рабочие данные; в архив исходников не включаются |

Старую карту можно открыть отдельно: `Assets/DawnGuard/BlackwoodV2/Generated/UserMap/BlackwoodUserMap.unity`. Не открывать обе игровые сцены одновременно при Play. **BlackwoodV2 удалять нельзя:** новая версия ссылается на её префабы и каталог.

## Проверка и передача

Проверка береговой логики без запуска редактора:

```powershell
pwsh -File ./Tools/Run-CoastChecks.ps1
```

Посмотреть состав архива исходников:

```powershell
pwsh -File ./Tools/Export-Source.ps1 -ListOnly
```

Создать архив в выбранном месте, например:

```powershell
pwsh -File ./Tools/Export-Source.ps1 -OutputPath D:/Exports/Blackwood-source.zip
```

Экспорт включает Assets **со всеми .meta**, Packages, ProjectSettings, Design, Tools и корневую документацию. Не включает Library, тестовые копии, архив истории, снимки проверок и личные настройки редактора. Это архив проекта, не готовая игровая сборка. После распаковки Unity заново создаст Library.
